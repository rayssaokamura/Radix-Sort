## 💻 Código-fonte

O arquivo `radix.c` contém a implementação do algoritmo **Radix Sort**.

O programa realiza a ordenação de um vetor de números utilizando o Radix Sort, com o **Counting Sort** como método auxiliar.

### Como executar

Para compilar o programa utilizando o GCC:

```bash
gcc radix.c -o radix
```

Depois, execute:

**Windows:**

```bash
radix.exe
```

**Linux:**

```bash
./radix
```

### Exemplo

**Vetor original:**

```text
170 45 75 90 802 24 2 66
```

**Vetor ordenado:**

```text
2 24 45 66 75 90 170 802
```
